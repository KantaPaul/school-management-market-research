# Sources

Access date for every web source below is **24 October 2026**, unless a published date is also shown. Prices, sales counts, and ratings are point-in-time snapshots. Marketplace mirrors sometimes differ from the official listing by a few sales or by a day on the “last update” field. Where that happened, the official CodeCanyon listing is preferred and the mirror is labelled secondary.

Evidence labels used throughout this research:

| Label | Meaning |
| --- | --- |
| Verified | Read from a primary page, official document, or a named secondary report of a named statistic. |
| Inference | A conclusion drawn from verified facts, not a fact by itself. |
| Hypothesis | A testable claim that interviews or a pilot must confirm. |
| Unknown | Not found, not checked, or contradicted without a basis to choose. |

This file does not repeat every claim. Each research document cites the source next to the claim.
